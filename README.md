🧪 A mysterious and nostalgic Minecraft Alpha-style project inspired by old lost versions, glitches, and creepy retro vibes.

## 🌑 About
Minecraft Alpha 0.0.0 is a fan-made experimental version designed to feel like a forgotten build from the early days of Minecraft. The world feels broken, silent, and unfinished — creating a strange horror atmosphere mixed with nostalgia.

## ⚠️ Features
• Old Alpha terrain generation  
• Creepy & atmospheric sounds  
• Glitched textures  
• Retro user interface  
• “Lost version” aesthetic  
• Horror-inspired gameplay vibes  

## 📱 Compatible With
• PojavLauncher  
• Minecraft Java Edition  

## 🛠️ Installation
1. Download the project files  
2. Put the folder into your Minecraft versions/mods directory  
3. Launch using the correct Java version  
4. Enjoy the cursed experience 👁️
